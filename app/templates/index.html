New plan

You can add more items to a plan later. For a multiblock, add one item per kind of block and take the counts from the structure preview in NEI.

How it works

1. Say what you want. An item, and how many.
2. Pick a recipe. Every recipe that makes it is listed, with the machine it runs on and the lowest voltage that will run it.
3. Keep going. That recipe's inputs are the next things to decide.
4. Stop where you like. Mark an item final — you will buy it, mine it, or you already have it — and it goes on the shopping list instead of expanding.
Demand for the same item on the same recipe is added up across the whole plan before it is rounded up to whole runs, so you are not charged for waste you would never produce. Spare output is listed, never subtracted for you.
